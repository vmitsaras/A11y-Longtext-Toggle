Start with real HTML

Keep all text visible in the authored markup. The button belongs outside the content region.

HTML
<div id="product-description">
  <p>Built for daily commutes and weekend train trips,
  this backpack keeps your essentials close. A padded
  sleeve protects your laptop, while the front pocket
  holds a notebook, travel card, and charging cable.</p>
</div>
<button type="button"
  data-target="product-description"
  data-show-more-text="Show full product description"
  data-show-less-text="Show less product description">
  Show full product description
</button>
3

Add the enhancement

Import both the class and its CSS. JavaScript options override matching data attributes.

JavaScript · with a CSS-aware bundler
import { A11yLongTextToggle } from
  'a11y-long-text-toggle';
import 'a11y-long-text-toggle/styles.css';

const button = document.querySelector(
  '[data-target="product-description"]'
);

if (button instanceof HTMLButtonElement) {
  const toggle = new A11yLongTextToggle(button, {
    collapsedLines: 3,
    fade: true,
  });
}
Using plain HTML without a bundler

The core class needs no build step. Copy these two source files into your project and load them directly. Keep the same content and button markup.

HTML · adjust paths to your files
<link rel="stylesheet" href="./a11y-long-text-toggle.css">
<script type="module">
  import { A11yLongTextToggle } from
    './a11y-long-text-toggle.js';

  const button = document.querySelector(
    '[data-target="product-description"]'
  );
  new A11yLongTextToggle(button, { collapsedLines: 3 });
</script>

03 / The reference

Small API.
The controls you need.

Create an instance with new A11yLongTextToggle(button, options). The createA11yLongTextToggle() export is an equivalent factory.

Instance methods

MethodWhat it does
expand()Reveal the full content and update the button’s label and state.
collapse()Return to the configured preview. If this would hide focused split content or a list item, focus returns to the button first.
toggle()Switch the saved expanded choice. The native button calls this for you.
refresh()Measure overflow and responsive conditions again. Call after CMS or application content changes.
isExpanded()Return the saved choice as a boolean. Outside a responsive condition, content is fully visible while that choice is retained.
destroy()Restore authored markup and remove listeners, observers, generated IDs, and pending work. The button can then be initialized again.

expand(), collapse(), toggle(), and refresh() accept { silent: true } to suppress that call’s events. Repeated expansion or collapse does not emit another state-change event. Expansion and collapse also accept { keepFocus: false } to skip re-focusing an already-focused button; this does not disable recovery before hiding a focused split remainder or list item.

Importing the package does not initialize buttons. The demo’s .js-long-text-toggle class is only a page-script hook. Reinitializing a button returns its existing instance and ignores new options. refresh() remeasures content without re-reading options; destroy and reinitialize if replacing the target or split remainder. Button labels use textContent, so use text-only labels.

Updating a CMS region
// After your application changes the region's text:
toggle.refresh();

// Before removing the component from the page:
toggle.destroy();

Options & data attributes

Pass settings in JavaScript or use the matching data-* attributes on the button. JavaScript takes precedence.

Option / attributeDefaultUse it for
targetdata-targetFrom the buttonA content element, ID, or selector. The button can also reference an ID through aria-controls. Missing content IDs are generated.
modedata-mode'lines''lines', 'height', 'items', or 'split'.
collapsedLinesdata-collapsed-lines3A positive integer or numeric string for visible lines in line mode.
collapsedHeightdata-collapsed-height'8rem'A CSS height for the preview in height mode.
collapsedItemsdata-collapsed-items3A positive integer or numeric string for visible direct li children in each ol or ul. Nested lists count separately; surrounding content stays visible.
autoHidedata-auto-hidetrueHide the button when the content does not need a preview.
showMoreTextdata-show-more-textAuthored button textA specific reveal label. Falls back to “Show full content” when the button has no text.
showLessTextdata-show-less-text'Show less'A specific collapse label. Include the content’s name when multiple toggles share a page.
fadedata-fadefalseAn optional visual fade for line or height previews. It does not replace the button.
allowInteractiveContentdata-allow-interactive-contentfalseBypass the focusable-content safeguard. Keep the default for clipping modes; use split mode for rich text with links.
responsiveSee forms belowNo width conditionActivate collapsing at a viewport or container width. A JavaScript value replaces all responsive attributes; null disables them.

Invalid modes use 'lines'; invalid counts use 3. Boolean options accept booleans or case-insensitive true/false, 1/0, yes/no, and on/off strings; invalid values use the default. Supply a valid CSS height: it is not validated by the class.

Responsive configuration

Choose one form per instance. A container must be an existing ancestor of the content, with width controlled by the surrounding layout.

JavaScript · alternative configurations
// Viewport: collapse only below 48rem.
new A11yLongTextToggle(button, {
  responsive: { mediaQuery: '(width < 48rem)' },
});

// Container: collapse at or below 640 CSS pixels.
new A11yLongTextToggle(otherButton, {
  responsive: { container: '#description-column', maxWidth: 640 },
});

HTML equivalents: data-media-query="(width < 48rem)", or data-container="#description-column" with data-container-max-width="640". Do not combine the two forms. maxWidth accepts a positive number or numeric string, not a CSS length.

Responsive changes preserve the saved choice, do not emit expand/collapse/toggle events, and defer hiding a focused button or collapsing content containing focus. aria-expanded describes the current presentation.

Lifecycle events

Listen on the content region. All events bubble, are not cancelable, and do not cross Shadow DOM boundaries. Each detail object contains instance.

JavaScript
import { EVENTS } from 'a11y-long-text-toggle';

content.addEventListener(EVENTS.expand, (event) => {
  console.log(event.detail.instance.isExpanded());
});
EVENTS.init
Initialization is complete. Attach the listener before construction to observe it.
EVENTS.expand / EVENTS.collapse
The saved state changes, before the corresponding toggle event.
EVENTS.toggle
A call to toggle() changes state.
EVENTS.overflowChange
Measured overflow changes. Detail also contains overflowing.
EVENTS.destroy
Cleanup and restoration are complete.
CSS hooks & visible focus

The package styles content; you style the button. Always provide a visible focus indicator.

CSS
.a11y-long-text {
  --a11y-long-text-fade-height: 2.5rem;
  --a11y-long-text-fade-from: rgb(255 255 255 / 0);
  --a11y-long-text-fade-to: Canvas;
}

button:focus-visible {
  outline: 3px solid Highlight;
  outline-offset: 3px;
}

State hooks: .a11y-long-text--collapsed, .a11y-long-text--expanded, .a11y-long-text--overflow, .a11y-long-text__fade, and .a11y-long-text__item--collapsed. Set line and height values through options or data attributes; initialization writes --a11y-long-text-collapsed-lines and --a11y-long-text-collapsed-height inline. Customize fade height and colors in CSS to match the host surface. No themes or animation are bundled; reduced-motion styles disable content transitions, forced colors remove the fade, and print styles reveal plugin-hidden content. Open host disclosures before printing.

Docs metadata & TypeScript

Use the separate metadata entry point when integrating this package into a documentation site.

TypeScript
import { docs } from 'a11y-long-text-toggle/docs';

The package root exports A11yLongTextToggleOptions, A11yLongTextToggleResponsiveOptions, A11yLongTextToggleInstance, A11yLongTextToggleEventDetail, A11yLongTextToggleOverflowChangeEventDetail, and A11yLongTextToggleEventMap as types. The event map does not globally augment DOM listeners.

04 / A considered baseline

The details matter.
So do the boundaries.

A native button and synchronized state are the starting point. Test the final integration with your content, browser, and assistive technology.

What to try

  • Tab to a toggle. Press Enter or Space. Confirm that its focus outline remains visible.
  • Check that the button exposes its label, expanded state, and content relationship through aria-expanded and aria-controls.
  • Disable JavaScript and reload. Every description and list item should remain readable.
  • Resize a responsive example. The reader’s choice stays saved; automatic changes do not move focus.
  • Print the page. The package stylesheet reveals the full content.

Choose the right mode

Clipping is visual.

Line and height modes keep the full text in the document and accessibility tree. Links or controls could remain keyboard reachable while visually clipped.

The default safeguard leaves content with common focusable descendants expanded and hides the toggle. Use split mode for interactive rich text. Its remainder is hidden from rendering and keyboard navigation when collapsed.

Item mode hides complete items with display: none and applies the focusable-content safeguard by default.

No screen-reader or cross-browser qualification is claimed here. The plugin adds no live region or disabled-state management; an authored disabled button keeps native behavior. ResizeObserver handles measurement when available; call refresh() after application-driven updates, or container width changes when no observer is available.
