# Changelog

## 1.0.0

### Major Changes

- Establish the 1.0.0 API under the unscoped `a11y-long-text-toggle` package name, with a vanilla JavaScript class, typed exports, progressive enhancement, native disclosure buttons, and documented integration examples.

### Minor Changes

- Export lifecycle event names and detail types, and emit expand/collapse events only when state changes.
- Add responsive activation using viewport media queries or ancestor container widths. Preserve the reader's expanded/collapsed choice and focus across resizes, support responsive data attributes, and document both forms with interactive demos.
- Add an item-count mode for ordered and unordered lists.
